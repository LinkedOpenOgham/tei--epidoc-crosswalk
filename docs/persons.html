Names on more than one stone

An edge inside one inscription is what the text says. A dashed arc between two stones is not: it means the same normalised name was written on both, and a shared name is a hypothesis, not a person. Several are patronymics — maqqas_treni is “son of Trenus” — which two unrelated men can carry. Every #? is its own unknown person, never merged with another.
